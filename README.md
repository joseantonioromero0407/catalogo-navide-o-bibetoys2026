# Catálogo Navideño BibeToys 2026

Landing oficial del catálogo de importación grupal BibeToys, respaldado por INTRAPROD.

## Funciones

- Visor del catálogo en alta calidad.
- Buscador por nombre, palabra relacionada o código.
- Selector desplegable con todos los productos.
- Copiado rápido de código y nombre.
- Formulario oficial de pedidos.
- Preguntas frecuentes y condiciones comerciales resumidas.
- Animaciones accesibles, diseño responsive y CTA fijo en celular.

## Desarrollo local

```bash
npm install
npm run dev
```

## Vercel

El repositorio incluye `vercel.json` y el script `build:vercel`. Al importar el repositorio en Vercel, la plataforma ejecutará la compilación estándar de Next.js y publicará cada cambio enviado a la rama principal.

No se requieren variables de entorno para esta versión.
